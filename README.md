# Tianzhuang Xu

Personal academic website, prepared for https://tianzhuangxu.github.io/.

## Publishing

Repository: `TianzhuangXu/TianzhuangXu.github.io`.
In Settings → Pages, choose **Deploy from a branch**, **main**, and **/(root)**.
The website uses static HTML, CSS, and JavaScript; no build command is needed.

## Editing

- `index.html`: biography, research, and network diagrams.
- `styles.css`: layout and typography.
- `network.js`: network perspective controls.
- `assets/Tianzhuang_Xu_CV.pdf`: downloadable CV.

Keep the canonical URL, `og:url`, `robots.txt`, and `sitemap.xml` aligned with the public address.
